# Web Design Guidelines

Use this skill when the project has a real user-facing web interface.

## Workflow

1. Review the visible layout, spacing, hierarchy, and navigation before polishing code details.
2. Check that forms, buttons, links, and empty states are easy to understand.
3. Make loading, error, success, hover, focus, and disabled states explicit.
4. Keep typography, contrast, and spacing comfortable on desktop and mobile.
5. Call out accessibility problems early instead of treating them as optional cleanup.

## Guardrails

- Do not ship a UI that only looks acceptable on one screen size.
- Do not hide key actions behind clever interactions or weak contrast.
- Prefer clear, calm, readable interfaces over flashy but confusing design.
