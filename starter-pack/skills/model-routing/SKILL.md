# Model Routing

Use this skill before larger work in Codex.

## Workflow

1. If the task is mostly planning, research, or tradeoffs, use the strong reasoning model.
2. If the task is mostly code implementation, use the implementation-focused coding model.
3. If the task is a fast small edit loop, use the faster coding option if available.
4. Re-route if the task changes shape.

## Guardrails

- Do not switch models just because code is mentioned once.
- Route by task type, not hype.
