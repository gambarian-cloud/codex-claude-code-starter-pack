# Executing Plans

Use this skill when the plan is ready and it is time to move carefully.

## Workflow

1. Confirm the current step.
2. Make the smallest change that completes it.
3. Run the check that proves the step worked.
4. Record what changed and what remains.
5. Move to the next step only after verification.

## Guardrails

- Do not batch many unverified changes together.
- Do not keep following a broken plan.
- If blocked, say what is blocked.
