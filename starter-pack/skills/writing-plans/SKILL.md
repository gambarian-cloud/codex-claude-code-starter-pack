# Writing Plans

Use this skill when the work should not be executed as one blob.

## Workflow

1. Define the goal and what done means.
2. Name the main risk or uncertainty.
3. Split the work into 3 to 7 steps.
4. Make each step observable and verifiable.
5. Put risky steps early.
6. Name the check that proves the step worked.

## Guardrails

- Do not write giant plans for tiny tasks.
- Do not hide uncertainty.
- Revise the plan when evidence changes.
