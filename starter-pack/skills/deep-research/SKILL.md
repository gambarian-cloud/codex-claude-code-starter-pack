# Deep Research

Use this skill when the task is:

- do a deep research pass on a topic
- compare multiple reports, repos, or catalogs
- build a source-of-truth plus field-evidence memo
- decide adopt now / experiment / watch / reject from real evidence

Do not use this skill for:

- quick fact lookup
- a single doc answer from one official page
- pure implementation work inside `src/`
- routine digest review after one run

## Workflow

1. Lock the research question first.
2. Split sources into `official truth` and `field evidence`.
3. Gather a small source set that can actually answer the question.
4. Compare the sources against the same decision frame.
5. Dedupe repeated ideas aggressively.
6. End with a decision memo, not a link dump.

## Output shape

- `Signal Assessment`
- `Adopt Now / Experiment / Watch / Reject`
- `Recommended Next Move`
- `Uncertainties`

## Guardrails

- Do not let one post or one list decide the outcome.
- Do not confuse popularity with proof.
- Do not stop at “many people mention it”; find the backing artifact.
- Do not leave the result as a brainstorm. End with a decision.
