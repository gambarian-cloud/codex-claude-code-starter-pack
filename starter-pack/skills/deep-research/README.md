## What this package contains

- `SKILL.md` - core workflow
- `references/` - rubric, artifact spec, completed example
- `assets/long-run-pack/` - starter file stack for long research passes
- `agents/openai.yaml` - skill metadata

## What makes it strong

- project context intake before outside research
- optional framing preflight when the path is unclear
- strict evidence admissibility
- contradiction -> decision mapping
- recommendation-first output instead of essay-first output

## Use it when

- the task needs multiple source layers
- the answer must be auditable
- contradictions matter
- the output should end in a recommendation, not a summary

Typical examples:

- compare these vendors
- research the safest workflow for this project
- build a source-of-truth memo before choosing a tool

This package is the benchmark winner in the Starter Pack deep-research comparisons.

## Do not use it when

- the answer is on one official page
- the task is a quick lookup
- the work is implementation-only
