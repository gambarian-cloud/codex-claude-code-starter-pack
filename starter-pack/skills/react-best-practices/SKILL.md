# React Best Practices

Use this skill when the project has a real React or Next.js UI.

## Workflow

1. Start with simple components and clear props.
2. Keep state close to where it is used.
3. Prefer readable composition over clever abstraction.
4. Make loading, empty, and error states explicit.
5. Keep styles and structure easy to scan.

## Guardrails

- Do not add a giant design system on day one.
- Do not overuse indirection for a small UI.
- Build the simplest correct version first.
