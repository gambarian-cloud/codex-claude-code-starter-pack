# General Use Profile

This profile is for a beginner who wants a calm everyday setup and does not need a specialized tool stack yet.

## What this profile adds

- no extra heavy tools beyond the core baseline
- a simple rule: stop at core unless you clearly need more

Why this profile exists:

- many beginners do better with fewer moving parts

## Install steps

1. Apply the core baseline from [core-baseline.md](../manifests/core-baseline.md).
2. Do not add extra MCP servers yet.
3. Do not add extra hooks or large skill packs yet.
4. Run [VERIFY.md](../VERIFY.md).

## Good fit

Choose this profile if you want help with:

- writing
- planning
- deep research
- research
- small coding tasks
- general assistant use

## Do not include by default

- frontend-specific skills
- app-builder bundles
- automation-heavy setups
