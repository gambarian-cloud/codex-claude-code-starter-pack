# GitHub Release Body - v0.6.6

Starter Pack 2026 for Windows is a one-button beginner setup for Codex and Claude Code.

What a new user does:

1. Download the ZIP
2. Extract it
3. Double-click `INSTALL-STARTER-PACK.cmd`
4. Wait for install
5. Read the short next-step note that opens automatically

What is new in v0.6.6:

- added `design-elevation` to the build-ready baseline
- added `frontend-design` to the build-ready baseline
- strengthened the default path for first websites and apps so the agent can set a bold first direction and then do a real refinement pass

Included in this release:

- beginner click-to-install path
- copy-paste path for Codex or Claude Code
- baseline for first websites, apps, presentations, and deep research
- bold frontend direction, design elevation, React guidance, UI review guardrails, browser checking, deploy guidance, presentation help, and deep research
- verification and rollback helpers inside `starter-pack/`

Recommended text for the release page:

If you are new to coding tools on Windows, download the ZIP, extract it, and double-click `INSTALL-STARTER-PACK.cmd`.
You do not need to use a terminal.
You do not need to understand code first.
